MB LEARNING HUB — PHASE 1 STARTER

Contents:
- index.html: responsive homepage and practical training application form prototype
- css/style.css: website styling
- js/app.js: mobile navigation, Swahili/English toggle and application form demo

IMPORTANT:
This is Phase 1 front-end prototype. The application form is NOT connected to a database yet and does NOT send or save applications.
Supabase database, secure Admin login/dashboard, real content management and payment verification will be implemented in later phases.

No student accounts.
No assignments, quizzes or certificates.
The platform plan includes:
- Business & Entrepreneurship
- Agriculture
- Personal Development
- Entertainment: music/audio, videos, short films, comedy, podcasts, news and articles
- Free and premium content
- Practical training application button for each service
- Admin-only management area (to be built in a later phase)

To preview:
Open index.html in a browser, or upload the project folder to a static hosting service.
Internet connection is needed for the optional Google Fonts import; the site otherwise uses fallback fonts.
